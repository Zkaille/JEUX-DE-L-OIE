# JEUX-DE-L-OIE
Projet | jeu de l'oie 
🌌 Jeu de l'Oie Astrale — Dark Fantasy Edition

Un jeu de l'oie web interactif, moderne et responsive, réinventé dans un univers Dark Fantasy aux teintes cosmiques (bleu nuit, violet magique et ornements dorés).

📜 Présentation du Projet

Ce projet propose une expérience complète du Jeu de l'Oie traditionnel (63 cases) directement jouable dans le navigateur web sans aucune installation requise. Il intègre une esthétique inspirée des nuits étoilées, de la magie astrale et des jeux de rôle fantasy.

✨ Fonctionnalités Principales

🎮 Modes de Jeu & Configuration

Pass & Play (Appareil Unique) : Jouez localement de 2 à 4 joueurs en vous passant l'écran à chaque tour.

Personnalisation des Héros :

Choix du pseudonyme.

Sélection de la couleur du pion (palette variée).

Sélection de l'avatar/icône magique (Mage 🧙‍♂️, Elfe 🧝‍♀️, Paladin 🛡️, etc.).

Règles dynamiques & Journal de Quête : Historique en temps réel des actions et déplacements de chaque joueur.

🎲 Mécaniques de Jeu Complexe

Case Départ (1) & Arrivée (63) : Mises en valeur visuellement sur le plateau.

Rebond d'Arrivée : Arriver au-delà de la case 63 fait reculer le pion d'autant de cases en trop.

Système de Duels ⚔️ : Si un joueur atterrit sur une case occupée, un affrontement d'arcane renvoie le joueur préexistant à la case départ !

Effets Spéciaux des Cases :

🚀 Oies Astrales : Double le mouvement effectué.

🏨 Auberge des Rêves : Fait passer 1 tour.

🌀 Labyrinthe des Illusions : Renvoyé en case 30.

💀 Trou Noir Astral (Case 58) : Retour immédiat au départ (case 1).

🔮 Cartes Mystiques : Pioche aléatoire d'événements (téléportation, saut de tour, boost).

🎨 Design & Animation

Interface 100% Responsive adaptative (PC, tablette, smartphone).

Animations CSS fluides pour le lancer de dés, les déplacements et les apparitions d'événements.

Effets sonores intégrés via l'API Web Audio (sans fichiers externes requis).

Feux d'artifice/confettis lors de la victoire.

🛠️ Technologies Utilisées

HTML5 / CSS3 / JavaScript (ES6+)

Tailwind CSS (via CDN) — Layout, thématique et design adaptatif.

FontAwesome 6 — Icônes de cases et d'interface.

Canvas Confetti — Effet de célébration de victoire.

Web Audio API — Génération des effets sonores synthétisés pour les dés et la victoire.
